# Хамстер

Симулятор поглаживания хомяка. Гладь мышкой или пальцем и собери все 19 его качеств: от доброго до злого. Корми семечками, поднимай, крути, устраивай дискотеку.

Играть: https://rust-hack.github.io/hamster/

Один файл `index.html`, без библиотек. Рисунок и звуки сделаны кодом. Таблица участников и счётчик заходов хранятся в базе Supabase: только ник и число качеств. В коде лежит публичный ключ базы, он не секрет — писать и читать можно только через четыре функции.

Можно поставить на экран «Домой»: в Safari «Поделиться» → «На экран „Домой“». Код восстановления в окне 🏆 переносит качества на другой телефон.
